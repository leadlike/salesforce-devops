# Contributing

- Open an issue to propose a chapter, correction or new CI/identity-provider example.
- Pull requests are welcome. Keep examples fictional: no real org IDs, tenant URLs, Federation IDs, e-mails or secrets.
- State the maturity status (`concept`, `local-tested`, `ci-validated`, `production-proven`) of anything you add, and link the evidence when possible.

## Language and review policy

- Write all new and updated documentation, pull request descriptions and commit messages in English.
- Propose repository changes on a branch and open a pull request. Do not push directly to the default branch.
- Wait for the repository owner's explicit approval before merging. Do not enable automatic merging.
- Do not rewrite published history, force-push or delete repositories.
